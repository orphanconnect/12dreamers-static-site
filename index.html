If you need to talk to someone

If someone is hurting you, or if you feel too sad or scared, tell a grown-up you trust. You can also reach help yourself:

  • In the United States, if you might hurt yourself, call or text 988. You can also text HOME to 741741. 988 Lifeline (opens in a new tab) · Crisis Text Line (opens in a new tab)

For grown-ups

What this site is

12 Dreamers is a free static shelf of learning links and a daily Bible verse for children in hard situations, including orphans, children in foster care, and any child who needs a kind place to learn. It is written to any child: you are loved.

There is no build step, no account, and no app to install for the site itself. It is plain HTML, CSS, and a little JavaScript.

What it collects

This website collects nothing. It does not set cookies. It does not use ads, analytics, or tracking pixels. It does not load third-party scripts, fonts, or images. It does not send a child’s activity to a server, because there is no server-side app.

If a child taps “I did it!” or chooses an age, that note is saved only in this browser’s localStorage, on this device. Clearing the browser’s site data removes it. Nobody else can see those stars.

Links that need a grown-up

  • Cards tagged “Ask a grown-up” need a parent, carer, teacher, or other trusted adult. That includes installing an app, using a library card, or creating an account.
  • Scratch: a grown-up creates the account for anyone under 13.
  • Code.org: puzzles work without an account. Under 13, a grown-up creates an account if progress should be saved.
  • Zearn, Libby, KidGeni, and Machine Learning for Kids need a grown-up to set them up.
  • Khan Academy lessons are free, and a child can start without an account. Khanmigo, the AI tutor, is paid and a parent or teacher turns it on. It is not a second free Khan Academy.
  • Mathsframe’s games marked free can be played as they are. Some worksheets and extras are paid.
  • Day of AI and Experience AI are classroom lessons. Do them together.
  • Teachable Machine can ask to use a camera or microphone.
  • ChatGPT is not listed for children. Its rules say 13+, with a parent.
  • Some tools are made by companies such as Google. Their own privacy rules apply once a child leaves this page. A grown-up should stay nearby the first time.

Help lines

  • Childhelp (United States), if a child is being hurt or if you need advice: call 1-800-422-4453. childhelphotline.org (opens in a new tab)
  • 988 Suicide & Crisis Lifeline (United States): call or text 988. 988lifeline.org (opens in a new tab)
  • Crisis Text Line (United States): text HOME to 741741. crisistextline.org (opens in a new tab)
  • Childline (United Kingdom): call 0800 1111 or visit childline.org.uk (opens in a new tab). Checked on the official Childline site, a free NSPCC service: the number is 0800 1111, it is free to call, and the call does not show on the phone bill.
  • Common Sense Media, for grown-ups checking other apps, games, and shows before a child uses them: commonsensemedia.org (opens in a new tab)

About the verses

The daily verse is chosen in the browser from a list stored on this site, using the device’s date, so it changes once a day without an account or a server. The words are from the Berean Standard Bible, which is in the public domain. A title line such as “A Psalm of David” is left off when it would get in the way. LORD is a name for God. The short note under the verse is a devotional written for a child, not a translation.

12 Dreamers is a free learning shelf for any child. You are loved.
